Hard rules (orchestrator-house — derived from canon, surfaced so you don't miss them):
- **`class="scene clip"` on the scene div** — `clip` is required by HF lint.
- **CSS scoping** — every rule prefixed with `#scene-<scene_id>`. No bare class selectors.
- **`tl.fromTo()` only** for entrances — never `tl.from()`, never bare `gsap.from()`.
- **No `data-composition-id` on the scene div.**
- **No `<template>` wrapper.**
- **No `<script src=".../gsap...">`** — root scaffold supplies GSAP once.
- **IIFE-wrap the entire script body** — un-IIFE'd `const tl` collides with
  the scaffold's top-level `const tl` and trips `hyperframes validate` with
  `Identifier 'tl' has already been declared`.
- **Density floor**: ≥ 8 elements visible at the hero frame, ≥ 2 BG
  decoratives with ambient motion (`tl.to()` on the seekable `tl`).
- **≥ 3 distinct eases**; first entrance offset 0.1–0.3s.
- **Final-fade (HR 4)**: permitted ONLY on the last scene (highest index in
  plan order). Otherwise NO `tl.to(..., {opacity: 0})` on the scene container.
- **Palette discipline (strict ⊆).** Use ONLY hexes from `state.compose.design.palette[*].hex` (already pre-baked with gradient-stop / highlight derivatives by `p4_design_system`). No improvised gradient stops, no shade variants, no near-palette derivatives. The HF canon `gate:design_adherence` (`~/.agents/skills/hyperframes/SKILL.md` §"Design Adherence" item 1) rejects any hex not literally in the palette set. If a needed shade isn't in the palette, choose the nearest palette entry — do NOT invent a 5-6 unit-off-channel variant. If you genuinely need an in-between value, prefer alpha-blending via `rgba(...)` (a literal palette hex parsed to channels + an alpha) or `tl.set/.to(..., {opacity: ...})`; both are gate-clean because the gate hex-extracts only `#RRGGBB` / `#RRGGBBAA` tokens.
  ```css

  background: linear-gradient(180deg, #2a221c 0%, #1f1a16 55%, #14100e 100%);
  /* ✅ every stop is a literal palette[*].hex — pre-baked by p4_design_system */
  ```

  - named families from `state.compose.design.typography[*].family` (Playfair Display, Inter — whatever DESIGN.md declares),

  - the system-UI whitelist (`system-ui`, `-apple-system`).

  Do NOT add named fallbacks like Georgia, Helvetica, Times New Roman. `gate:design_adherence` (`~/.agents/skills/hyperframes/SKILL.md` §"Design Adherence" item 2) flags any token not in `typography[*].family` ∪ generics ∪ whitelist.
